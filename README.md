# Azeroth Survivors fixes

Small helpers for playing [Azeroth Survivors](https://wow.aethus.pl/) in a browser.
Nothing here modifies the game itself.

| folder | what |
|---|---|
| [`browser-fixes/`](browser-fixes/) | Windows 11: play without the browser's "Press Esc to exit full screen" and "has control of your pointer" overlays. An Electron wrapper (recommended), Edge/Chrome kiosk scripts, and Firefox preferences. Start with its [README](browser-fixes/README.md). |
| [`addons/`](addons/) | **HeroHealthBar**, an in-game addon that draws a plain health bar just under your hero. Install `HeroHealthBar.zip` from the game's Options → AddOns → install; type `/hpbar` in chat for options. The unzipped source is alongside. |
